# Seguridad

LibreIO no usa internet, no tiene cuentas ni telemetría y solo lee y escribe los archivos que el usuario abre o guarda. Los instaladores no están firmados; se pueden verificar comparando con los publicados en [Releases](https://github.com/guillermoleale/LibreIO/releases), que se construyen en GitHub Actions a partir del tag correspondiente.

Si encontrás un problema de seguridad, abrí un aviso privado desde la pestaña Security del repositorio en lugar de un issue público.
