# Cambios

Todas las versiones se publican como tags `vX.Y.Z` con instaladores en GitHub Releases y la web en GitHub Pages.

## 1.5.1

- Todos los módulos exportan su reporte a `.txt` y `.md` y lo copian al portapapeles
- Ctrl+Enter resuelve en cualquier módulo
- CHANGELOG

## 1.5.0 (fase 6)

- Manual para alumnos en `docs/manual.md`
- Versión web que funciona sin conexión después de la primera carga (PWA con service worker)
- Cortes de Gomory como método entero alternativo, con pestaña Cortes

## 1.4.0 (fase 5)

- Programación dinámica: mochila con varias unidades y diligencia con etapas dadas o deducidas, con la tabla de cada etapa
- Cadenas de Markov: clasificación de estados, distribución en n pasos, estado estable, tiempos medios de primer paso y de recurrencia y análisis de estados absorbentes

## 1.3.0 (fase 4)

- Colas: M/M/1, M/M/s, M/M/1/K, M/M/s/K, M/M/s con población finita, M/G/1, M/D/1 y M/Ek/1 con costos y análisis de capacidad
- Inventarios: EOQ y variantes, una sola compra y revisión continua con gráficos
- Decisiones: tabla de pagos, revisión bayesiana, árboles de decisión y juegos de suma cero

## 1.2.0 (fase 3)

- Redes: camino mínimo, flujo máximo, árbol de expansión mínima y viajante, con el grafo dibujado y el paso a paso
- PERT/CPM: tiempos y holguras, red de actividades, Gantt, probabilidades y compresión

## 1.1.0 (fase 2)

- Análisis paramétrico de lado derecho y de coeficiente
- Programación entera por ramificación y acotamiento con el árbol navegable
- Transporte, transbordo y asignación con MODI y método húngaro
- Entrada tabular sincronizada con el texto y archivos `.io.json`

## 1.0.0 (fases 0 y 1)

- Lenguaje de modelos compatible con LINDO, simplex con dos fases y Big M, pivoteo manual, sensibilidad, dual, reportes combinado y clásico, tableau clásico y método gráfico
- Aritmética exacta con fracciones, app de escritorio con Tauri y versión web
